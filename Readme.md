# Programming Fundamentals, Fall 2026

This is the course repository. Fork it to your own GitHub
account, then work in your fork.

## Folders

- Assignments: one folder per graded assignment.
- Modules: in-class practice code.

## How to use this repository

1. Fork this repository to your account.
2. Clone your fork to your computer.
3. Add your work in the correct folder.
4. Commit and push to your fork.
5. Submit your fork's web address in the learning
   management system.

Assignment instructions, deadlines and rubrics are posted
in the learning management system, not here.
